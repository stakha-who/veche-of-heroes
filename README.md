# Вече героев

Учебный веб-кабинет для переноса игровых аккаунтов между регионами. Сервер проверяет владельца аккаунта, маршрут, баланс и срок ожидания. Смена региона, списание валюты и запись в историю выполняются в одной транзакции.

**Стек** — PHP 8.4, PDO, MySQL 8.4 и Docker Compose. Приложение организовано по MVC.

## Структура проекта

| Каталог | За что отвечает |
|---|---|
| `public/` | Точка входа `index.php`, маршрутизация HTTP-запросов и стили. |
| `app/controllers/` | Обработка запросов, проверка доступа и вызов операций. |
| `app/models/` | Работа с MySQL и правила переноса, рейтинга и матчей. |
| `views/` | HTML-шаблоны страниц кабинета. |
| `database/migrations/` | SQL-миграции схемы базы данных. |
| `bin/` | Применение миграций, загрузка демоданных и просмотр демонстрационного состояния. |
| `tests/` | Автоматические проверки серверных операций. |

## Запуск

Для запуска требуется работающий Docker Desktop. Команды выполняются в PowerShell из папки приложения.

```powershell
docker compose up --build -d
docker compose logs --tail 40 web
```

[Кабинет](http://127.0.0.1:8080/) доступен после запуска. Для демонстрации используется `demo` с паролем `veche-demo`. Для проверки разграничения доступа используется `guest` с паролем `veche-guest`.

При запуске применяются миграции. Демоданные загружаются при `APP_DEMO=1`. Если порт 8080 занят, свободный порт задаётся переменной `APP_PORT` в локальном файле `.env`. Пример настроек приведён в `.env.example`. Для остановки приложения используется `docker compose down`. Данные MySQL хранятся в отдельном томе Docker.

## Демонстрационные сценарии

| Аккаунт | Сценарий |
|---|---|
| Яромир | Начинает в EUW с 3000 золотых, уровнем 27, инвентарём и рангом «Изумруд II». Перенос в ASIA оставляет 400 золотых и открывает калибровку с предварительного Изумруда II. |
| Велимир | Начинает в EUNE с 2600 золотых. После разрешённого переноса в кошельке остаётся 0. |
| Добрыня | Выезд из KR в EUW разрешён. Перед списанием появляется предупреждение о закрытом возврате. |
| Мирослава | Играет в RU. Попытка переноса отклоняется без списания. |
| Ратибор и Весна | Ратибору не хватает золотых. У Весны действует кулдаун «90 восходов солнца». |
| Любомир | В ASIA подтверждён Алмаз IV, кулдаун истёк. При возвращении в EUW старый Изумруд из истории и предварительный Алмаз IV видны отдельно. После трёх матчей профиль показывает фактический итог. |
| Зоряна | Показывает ранг прошлого сезона до новой калибровки. |

### Матчи и рейтинг

Кнопка «Начать матч» в профиле запускает матч на сервере текущего региона. Демонстрационный результат выбирается на странице матча. В сценарии Яромира две победы дают MMR 1800, а калибровка всё ещё показывает 2 из 3. Матчи каждого аккаунта нумеруются с 0. За победу начисляется 10 очков, за поражение снимается 8. При калибровке изменения составляют +20 и −16. На 50 очках ранг повышается, а остаток переносится в следующий дивизион. Уход ниже нуля понижает ранг. Для Любомира три победы после переноса дают Алмаз III, а три поражения — Изумруд I.

В профиле можно добавить 2600 золотых, пропустить ожидание переноса, добавить случайный предмет из каталога или удалить один случайный экземпляр из инвентаря. Инвентарь следует за аккаунтом при смене региона. Кнопка «Удалить аккаунт» скрывает профиль из списка после подтверждения. На странице «Мои аккаунты» кнопка «Откатить изменения» возвращает стартовые демонстрационные регионы, кошельки, ранги и инвентарь. После подтверждения она удаляет созданные вручную аккаунты, сыгранные матчи и историю переносов этого пользователя.

Скрытое значение можно проверить из терминала запущенного демонстрационного проекта:

```powershell
docker compose exec web php bin/demo-state.php Яромир
```

## Автоматические проверки

```powershell
docker compose -p veche-of-heroes-tests run --build --rm -e APP_TEST=1 web sh -c 'php bin/migrate.php && php bin/seed.php && php tests/run.php'
```

Команда использует отдельный проект Compose и отдельную базу. Проверяются маршруты, списание, повторы, одновременные подтверждения переноса, откат, калибровка, нумерация матчей, очки ранга, сервер матча, смена сезона и действия с инвентарём.
