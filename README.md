# Вече героев

Учебный веб-кабинет для переноса игровых аккаунтов между регионами. На текущем этапе реализованы стартовая страница, подключение к MySQL и запуск миграций.

## Запуск

Для запуска требуется Docker Desktop. Команда выполняется из корня репозитория.

```powershell
docker compose up --build
```

[Стартовая страница](http://127.0.0.1:8080/) открывается после запуска контейнеров. Состояние подключения к MySQL проверяется по адресу [`/health`](http://127.0.0.1:8080/health).

## Структура проекта

| Файл | За что отвечает |
|---|---|
| `compose.yaml` | Конфигурация контейнеров PHP и MySQL. |
| `Dockerfile` | Сборка образа PHP и запуск миграций перед запуском веб-сервера. |
| `public/index.php` | Точка входа, маршрутизация и проверка подключения к MySQL. |
| `views/home.php` | Шаблон стартовой страницы. |
| `app/database.php` | Подключение к MySQL через PDO. |
| `bin/migrate.php` | Применение SQL-миграций и учёт выполненных миграций. |
