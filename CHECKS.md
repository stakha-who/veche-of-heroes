# Протокол итоговой проверки

Автоматический набор проверок находится в `tests/`. Команда запуска приведена в README.

| Сценарий | Ожидаемый результат |
|---|---|
| EUW → ASIA с 3000 золотых и MMR 1800 | ASIA, баланс 400, MMR 1780, предварительный ранг и одна запись переноса. |
| Повтор подтверждения | Прежний результат. Баланс и число записей сохраняются. |
| Вторая форма с прежним состоянием | Отказ по устаревшим условиям. |
| Ошибка вставки истории | Перенос откатывается вместе с балансом, регионом, кулдауном и рейтингом. |
| KR → EUW и возвращение из EUW | Выезд проходит. Возврат отклоняется после истечения кулдауна. |
| RU → EUW и EUW → RU | Оба направления закрыты, списания нет. |
| Матч после переезда | Назначается сервер нового региона. |
| Третий уникальный матч | Итоговый ранг подтверждается. Повтор результата не меняет счётчик. |
| Нумерация матчей | У каждого аккаунта первый матч №0. Следующий матч этого же аккаунта имеет №1. |
| Победа и поражение | +10/−8 после калибровки, +20/−16 во время неё. На 50 очках происходит повышение, при уходе ниже нуля — понижение. |
| Пополнение и пропуск ожидания | Кошелёк увеличился на 2600. Пропуск ожидания сохраняет историю и ограничения маршрутов. |
| Удаление аккаунта | Владелец подтверждает действие. Профиль исчезает из списка и недоступен по прежней ссылке. |
| Добавление и удаление предмета | Добавляется одна единица из каталога, удаляется одна имеющаяся единица. Состав и количество сохраняются при переносе. |
| Граница сезона | Начинается калибровка нового сезона, архивный ранг сохраняется. |

При обновлении уже присвоенные ранги сохраняются. Открытую калибровку в текущем сезоне, в которой сыграно три матча или больше, завершает результат третьего матча. История матчей и набранный MMR сохраняются. Для открытых рангов прежние 50 и более очков пересчитаны в 49, чтобы сохранить текущий дивизион.

Фактические результаты фиксируются выводом команды проверки.
